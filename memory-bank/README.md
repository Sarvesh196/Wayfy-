# Wayfy memory bank

These notes give AI assistants durable project context across sessions. Read
`project-brief.md`, `tech-stack.md`, `architecture.md`, `decisions.md`, and
`current-status.md` before making substantial changes.

Keep the notes concise and update them when project decisions or implementation
status changes. The repository code and configuration are the source of truth
for what is currently implemented. Never store credentials, tokens, or other
secrets here.
